# מקריא קולי

מדביקים טקסט עברי — והוא נקרא בקול, עם הדגשת המילה המוקראת.
אין כאן שאלות ואין התקדמות: זה כלי, לא קורס.

**מזהה:** `reader` · **שלב:** `public` · **קובץ:** `index.html`, 1,648 שורות

## למה היא אפליקציה ולא נושא

**הדבק-והקרא הוא אינטראקציה שאין במנוע.** אין כאן `buildQ`, אין
מאגר שאלות ואין `content.js` שסורק אותה — ולכן גם אין לה דוח
תוכן, וזה תקין.

## אין לה `BUILD` — וזה לא באג

היא נושאת **מפתח קאש בלבד**:

    navigator.serviceWorker.register("sw.js?v=39-pwa1");

אין לה פוטר שמציג גרסה ללומד, ולכן אין מה להציג. המנגנון תלוי
אך ורק ב-`?v=`. **אל תסיק מהיעדר `BUILD` שאין מה להעלות** —
נגעת בקובץ, העלה את המפתח. `node .claude/qa/status.js` מסמן אותה
״מפתח בלבד״, וזה המצב התקין שלה.

## הקראה — מעקב אחרי המילה

`onboundary` מסמן את המילה שנאמרת ברגע זה. שלושה מנגנונים נוספים
מכסים כשלים שקטים של Web Speech — שומר-ער, `_activeU` ו-watchdog —
וההסבר המלא ב-`CLAUDE.md`, ״מנוע ההקראה — ארבעה מנגנונים״.
`node .claude/qa/voice.js` בודק את ארבעתם מול `speechSynthesis` מזויף.

## מפתחות `localStorage`

| מפתח | מה |
|---|---|
| `LG_KEY` | שפת הממשק |
| `PREFS_KEY` | העדפות ההקראה — קול, מהירות |

אין כאן התקדמות לשמור, ולכן אין מפתח מצב.

## בדיקות שנוגעות לה

    node .claude/qa/serve.js
    node .claude/qa/smoke.js reader
    node .claude/qa/voice.js          # ארבעת מנגנוני ההקראה
    node .claude/qa/cache.js
    node .claude/qa/all.js

## PWA — מה שהופך אותה לאפליקציה

`manifest.json` (‎3‎ אייקונים, `display: standalone`, `lang: he`, `dir: rtl`)
ו-`sw.js` שמצרף מראש **5 נכסים**. אחרי טעינה ראשונה היא עובדת
בלי אינטרנט, ואפשר להתקין אותה על מסך הבית.

**המטמון שלה הוא `reader-` ושלה בלבד.** שנים־עשר קובצי ה-`sw.js`
מצרפים את אותם `/legal/terms.js` ו-`/legal/protect.js`, כל אחד
למטמון משלו — ולכן נגיעה ב-`legal/` מחייבת להעלות את **כל**
המפתחות יחד. ההסבר המלא ב-`CLAUDE.md`, ״מלכודת הקאש של `legal/`״.

## גרסה — שתי מחרוזות, לא אחת

    (אין BUILD — ראו למעלה)
    navigator.serviceWorker.register("sw.js?v=39-pwa1");

`sw.js` גוזר את שם המטמון מ-`?v=` שבכתובת הרישום, **לא** מ-`BUILD`.
עדכון של אחד בלי השני משאיר את הלומד עם הקוד הישן.
`node .claude/qa/cache.js` נופל על אי־התאמה, וגם על מפתח שכבר
קיים ב-`origin/main` עם תוכן אחר.

## ״עזרה מהמורה״ (ג׳וש)

מחווטת בארבע נקודות: תגית `<script src="/tutor/tutor.js">`,
`TUTOR.mount(...)`, קריאת `TUTOR.open()` מהנתב, והנתיב ב-`PRE`
שב-`sw.js`. **הכפתור אינו מוצג** כל עוד `API` ריק ב-`tutor/tutor.js`;
ההפעלה היא `node .claude/qa/enable-tutor.js <כתובת>`. הצד השרתי
כולו ב-`tutor-api/worker.js`, והתפקיד של האפליקציה הזאת נמצא שם
ב-`ROLE`.

## מה אין כאן

אין `npm install`, אין build step, אין framework ואין תלות חיצונית.
