# ביולוגיה לבגרות — בקול

אפליקציית תרגול ביולוגיה לבגרות (5 יח״ל, שאלון 043381) עם רמז, הסבר והקראה: בעברית, ערבית, רוסית ואנגלית.

- חמישה נושאים לפי נושאי הליבה של תוכנית הלימודים של משרד החינוך: תא ורמות ארגון, מהגן לתפקוד, הומאוסטזיס ובקרה, תורשה ואבולוציה, אקולוגיה וסביבות חיים.
- 30 שאלות מקוריות (שני פריטים לכל נושא ורמה, שלוש רמות), ארבע שפות; כל שאלה עם רמז והסבר. מאגר ראשוני, מיועד להרחבה.
- מקור: תוכנית הלימודים ומבנה השאלון של משרד החינוך (pop.education.gov.il, ביולוגיה לחטיבה עליונה; שאלון 43381). השאלות נכתבו מחדש בידי בקול, עם קרדיט למשרד החינוך. אינן העתק של בחינה.
- נבנתה מ-motal (אותו מנוע חידון). לא נבדקה בידי מורה לביולוגיה.
- מבנה: PWA סטטי, כל הנתונים מקומיים (localStorage), בלי שרת.
