# מעבדת סוכנים — מצב הדמיה

ממשק בעברית ל-RTL שמנהל משימות, ומריץ על כל משימה תהליך של שלושה
תפקידים: **מתכנן → מבצע → מבקר**. הכול נשמר ב-SQLite מקומי.

> **מצב הדמיה — ללא חיבור אמיתי למודלים.**
> הספק היחיד הרשום הוא `mock`, והוא מייצר את כל התשובות מקומית
> מתוך `sha256` של הבקשה והזרע. אין קריאות רשת, אין מפתחות API,
> ואין חיוב כספי. `get_provider()` דוחה כל שם ספק אחר, והבדיקה
> `test_runs_with_the_network_switched_off` מוכיחה זאת: היא מפילה
> כל ניסיון לפתוח socket, והתהליך עובר במלואו.

## מה צריך

**פייתון 3.9 ומעלה, וזה הכול.** ספרייה סטנדרטית בלבד — `sqlite3`,
`http.server`, `json`, `unittest`. אין `pip install`, אין `npm`,
אין קובץ דרישות ואין שלב בנייה.

## הפעלה ב-Windows

1. מתקינים פייתון מ-python.org, ומסמנים בהתקנה **Add Python to PATH**.
2. פותחים את תיקיית `tools\agent-lab` בסייר הקבצים.
3. לחיצה כפולה על **`start.bat`** — השרת עולה והדפדפן נפתח לבד.

או משורת פקודה (`cmd` או PowerShell):

```
cd path\to\tools\agent-lab
py -3 run.py
```

ואז לפתוח בדפדפן: <http://127.0.0.1:8123/>

בדיקות ב-Windows: לחיצה כפולה על **`test.bat`**, או `py -3 run_tests.py`.

אם פורט 8123 תפוס: `py -3 run.py --port 9000`.
אם חומת האש של Windows שואלת — אפשר לסרב. השרת מאזין ל-127.0.0.1
בלבד ואינו זקוק להרשאת רשת.

## הפעלה ב-Linux ו-macOS

```
cd tools/agent-lab
python3 run.py            # http://127.0.0.1:8123/
python3 run_tests.py      # כל הבדיקות
```

דגלים: `--port`, `--host`, `--db <נתיב>`, `--open` (פותח דפדפן).

## איך זה עובד

| שלב | מה הוא עושה |
|---|---|
| **מתכנן** | קורא כותרת ותיאור, ומפרק לשלושה עד חמישה צעדים |
| **מבצע** | מבצע כל צעד. פלט מסומן `בוצע` או `בוצע חלקית` |
| **מבקר** | קורא כל פלט ומחליט `אושר` או `חזר לתיקון` |

צעד שנדחה חוזר למבצע **פעם אחת** (סבב תיקון), והמבקר מכריע סופית —
`אושר` או `נדחה`. משימה שכל צעדיה אושרו מקבלת סטטוס **הושלמה**;
אחרת **נכשלה**. ביצוע שהוכרז חלקי לעולם אינו מאושר, גם אם חוות
הדעת חיובית.

הכול נגזר מהזרע של המשימה (sha256 של הכותרת והתיאור), ולכן **אותה
משימה נותנת בדיוק אותה ריצה** בכל מחשב ובכל פעם. זה מה שמאפשר
לבדיקות להשוות פלט מלא ולא רק צורה.

## הקבצים

```
run.py                 הפעלה

agentlab/db.py         SQLite: tasks, steps, events
agentlab/providers.py  הספק המדומה. mock בלבד
agentlab/pipeline.py   מתכנן → מבצע → מבקר, וסבב התיקון
agentlab/server.py     שרת HTTP ו-API
web/index.html         הממשק. עברית, RTL, קובץ אחד
tests/                 35 בדיקות
data/agentlab.db       נוצר בהפעלה הראשונה (אינו נכנס ל-git)
```

## ה-API

| פעולה | נתיב |
|---|---|
| מצב המערכת | `GET /api/health` |
| רשימת משימות | `GET /api/tasks` |
| יצירת משימה | `POST /api/tasks` — `{"title": "...", "description": "..."}` |
| משימה + צעדים + יומן | `GET /api/tasks/<id>` |
| הרצת התהליך | `POST /api/tasks/<id>/run` |
| מחיקה | `DELETE /api/tasks/<id>` |

כל תשובה נושאת `"simulation": true`.

## מה עוד לא קיים

ספק אמיתי, משתמשים והרשאות, ריצה ברקע (הריצה כרגע סינכרונית
בתוך הבקשה), וייצוא תוצאות. אבן הדרך הזאת עוצרת כאן במתכוון.
