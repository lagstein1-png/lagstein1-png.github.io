# מדע וטכנולוגיה לחטיבה, כיתות ז-ט (science-mid) - בקול

פיילוט של אפליקציית מדע וטכנולוגיה לחטיבת הביניים. שלב: build, מאחורי שער פנימי (?internal=shlav-internal-science-mid), noindex.

- יחידות כתובות: ז0 מתחילים לחקור בבטחה, ז1 גוף חומר ומדידה, ח9 כוחות. שאר היחידות מופיעות כ"בקרוב".
- רצף שיעור: תופעה, מושג, דוגמה מודרכת, בדיקה קצרה. סוף יחידה: חזרה לתחזית הראשונה, בלי ציונים.
- ארבע שפות (עברית מקור; ערבית, רוסית ואנגלית בתרגום מכונה), שכבת הקלטות דרך /speech/recorded.js (מניפסט ריק), לימור דרך TUTOR.mount ו-BARAK.register עם מזהה scimid.
- נושאים לפי מפרטי משרד החינוך (מדע וטכנולוגיה לחטיבה, תשפ״ז). כל הטקסטים והשאלות כתובים מחדש; שום תוכן של הוצאה מסחרית לא הועתק.
- מפתח אחסון: scimid-v1. מטמון sw: scimid-.
