# מורשת ודת האיסלאם לבגרות — בקול

אפליקציית תרגול לבגרות במורשת ודת האיסלאם עם רמז, הסבר והקראה: בעברית, ערבית, רוסית ואנגלית.

- חמישה נושאים לפי תחומי הבחינה: קוראן (נסח, אעג'אז), חדית' (אל-מועטא, בדיית חדית'), אמונה (ספרי אללה ושמותיו), הלכה (זכאת, אג'מאע) וסירה (בדר, אל-אסראא והמיעראג').
- 86 שאלות מקוריות, שלוש רמות, ארבע שפות; כל שאלה עם רמז והסבר.
- מבוסס על מבנה התחומים של בחינות משרד החינוך (pop.education.gov.il, בחינות דת האיסלאם 074501) והשאלות נכתבו מחדש בידי בקול, עם קרדיט למשרד החינוך. אינן העתק של בחינה.
- נבנתה מ-hebrew-arab (אותו מנוע חידון). לא נבדקה בידי איש דת או מורה; מומלץ סקירה לפני פרסום.
- מבנה: PWA סטטי, כל הנתונים מקומיים (localStorage), בלי שרת.
- הקראה: חמשת המנגנונים, ומעליהם השכבה המוקלטת (`/speech/recorded.js`). נמדד 5.10.2026 ב-`node .claude/qa/record.js --check`: 551 הקלטות על הדיסק, המניפסט תואם, כיסוי 374/584. מה שאין לו קובץ נופל לקול המכשיר.
- לימור (״עזרה מהמורה״): הכפתור קיים, אבל **אין ל-islam מפתח `ROLE` ב-`tutor-api/worker.js`** (נמדד 5.10.2026). `readBody` דוחה אותה ב-400, והלקוח נופל למוח המקומי — לימור עונה, בלי ידיעת המקצוע.
- סריקת תוכן: `node .claude/qa/content.js islam` רצה 5.10.2026 — 2,250 שאלות, 0 FAIL, 3 REVIEW (מיעוט וריאציה, אפס הסברים ״למה לא״ למסיחים, ודליפת-הקראה שהיא אותה התראת שווא שיש בכל משפחת החידון).
- אף אחת מ-86 השאלות אינה נושאת עדיין הסבר ״למה לא״ לכל מסיח. המנוע תומך בזה; התוכן לא נכתב.
