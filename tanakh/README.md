# תנ״ך לבגרות — בקול

אפליקציית תרגול תנ״ך לבגרות (שאלונים 1261/1262) עם רמז, הסבר והקראה — בעברית, ערבית, רוסית ואנגלית.

- שני מסלולים: 1261 (תורה ונביאים ראשונים) ו-1262 (נביאים אחרונים וכתובים).
- ששה נושאים מבוססי תוכנית הלימודים של משרד החינוך; הניסוח מקורי של בקול.
- כל שאלה נושאת רמז, הסבר, ותשובה שגויה עם הסבר "למה לא" לכל אפשרות.
- בונה מבחנים כיתתי עם ציונים דרך וואטסאפ, בלי שרת ובלי חשבון.
- מבנה: PWA סטטי, כל הנתונים מקומיים (localStorage), בלי שרת.

מוסתרת כרגע מהדף הראשי; נפתחת עם מפתח פנימי (?internal=...).
