## למה

‏O-191: האתר המפורסם שקל 1.2GB מול מגבלת ה-1GB של GitHub Pages
(״Published GitHub Pages sites may be no larger than 1 GB״). ‏984MB
מתוכו הם 22,109 קובצי MP3 של השכבה המוקלטת, והאתר בלעדיהם שוקל
213MB — מהם 158MB ב-`marketing/`.

## למה שניים ולא אחד

‏`record.js --plan` ב-10.10.2026: 25,102 מחרוזות, מוקלטות 20,073,
**חסרות 5,029**. בדיסק 22,406 קבצים שוקלים 984MB — 44.9KB לקובץ —
ולכן המאגר **השלם** הוא 1,143MB, מעל 1,024. ריפו אחד היה נחצה
כמעט מיד, והפעם בלי שאיש מודד.

שני דליים מאוזנים, כשיושלמו: 572MB ו-571MB. היום: 579MB ו-405MB.
התקרה בכלי היא **900MB** ולא 1,024 — ריצת ההקלטה היומית מוסיפה בלי
לשאול, ושער שנדלק ב-1,024 נדלק אחרי שהאתר כבר לא מתפרסם.

## המתג — ארבעה מקומות, וכולם יחד

1. `HOST_1` ו-`HOST_2` ב-`speech/recorded.js` (שורות 85–86).
2. `const AUDIO` ב-**41** קובצי `sw.js` — ה-origin, בלי הנתיב:
   `https://lagstein1-png.github.io`.
3. `record.yml` — לדחוף את ה-MP3 לריפואים ולא לכאן. דורש Secret עם
   הרשאת כתיבה אליהם; ל-`GITHUB_TOKEN` יש הרשאה לריפו הזה בלבד.
4. `BUILD` ו-`?v=` של כל ארבעים האפליקציות — `recorded.js` יושב
   ב-`PRE` של כולן.

**‏1 ו-2 יחד, ולא אחד מהם.** ‏`recorded.js` בונה את הכתובת ו-`sw.js`
מחליט אם המקור הזה נכנס למטמון. מי שהפך את הראשון ושכח את השני מקבל
קול **שעובד ברשת ומת אופליין** — בלי שגיאה, בלי אזהרה, ובדיוק אצל מי
שהתקין את האפליקציה. `audio-size.js --check` מפיל על זה, והוכח אדום
בשלוש צורות (FINDINGS.md, 10.10.2026).

## הנוהל

```
# 1. בונים את שני העצים (מעתיק, לא מוחק)
node .claude/qa/audio-move.js                      # מה ייבנה
node .claude/qa/audio-move.js --build /tmp/au
node .claude/qa/audio-move.js --check /tmp/au      # מניפסט מול עץ

# 2. יוצרים ב-GitHub: lagstein1-png/bekol-audio ו-bekol-audio2 (ציבוריים)
#    — פעולת הבעלים. סשן כבול לריפו שהוגדר לו, ו-POST /user/repos מוחזר 403.

# 3. דוחפים (הפקודות המדויקות מודפסות בסוף --build)

# 4. Settings → Pages → Deploy from a branch → main / (root), בשניהם
#    — פעולת הבעלים. ה-Pages API חסום מהפרוקסי של הסשן.

# 5. מאמתים שהקבצים מוגשים:  Actions → live-check

# 6. הופכים את המתג (1+2 יחד), מעלים ארבעים מפתחות, ורק אז:

# 7. קומיט נפרד שמוחק את */audio/**/*.mp3 מהריפו הזה.
#    נפרד בכוונה — git revert אחד מחזיר 984MB.
```

**הסדר אינו ניתן לקיצור.** עד שלב 7 הקבצים יושבים בשני מקומות, ואין
רגע שבו הם במקום אחד בלבד. מי שמוחק לפני שהריפואים מוגשים מקבל
‏22,109 קליפים ששולמו ונופלים ל-404 — ואז `has()` אומר ״יש קובץ״,
‏`play` מחזיר true, ו-`onerror` מחזיר את הלומד לקול המכשיר. הוא
לא נשתק, אבל הקול שהבעלים שמע ובחר נעלם.

## מה נשאר פתוח אחרי המעבר

**הגודל בהיסטוריה.** מחיקה בקומיט רגיל מוציאה את 984MB מהאתר
ה**מפורסם** — זו המגבלה הקשה — אבל ההיסטוריה ממשיכה להחזיק אותם,
וההמלצה של GitHub לגודל מאגר (1GB) נשארת חצויה. הוצאה מההיסטוריה היא
‏`force-push`, ו-`CLAUDE.md` אוסר אותו. **הכרעת בעלים.**

**‏`record.js --check` מאבד את מה שהוא בודק.** הוא משווה מניפסט
לקבצים שעל הדיסק. ברגע שהקבצים אינם כאן, הוא ישווה מניפסט לכלום —
וזו בדיוק משפחת O-210, בדיקה שמדלגת ונראית כמי שעברה. ההוכחה צריכה
לעבור ל-`record.yml`, שרואה את שני הצדדים ברגע שהוא מייצר אותם.
