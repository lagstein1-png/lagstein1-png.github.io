# מרגל הסשן

> הועבר כלשונו מ-`CLAUDE.md` ב-17.9.2026, כדי לקצר את מה שנטען בכל סשן.
> הכללים כאן מחייבים בדיוק כמו שם. הפניות ״למעלה״ ו״למטה״ מכוונות לסעיפים ב-`CLAUDE.md` או במסמכים האחרים כאן (הטבלה בראש `CLAUDE.md`).

## מרגל הסשן

    .claude/spy.sh              סשן חדש, ואחריו סיכום בעברית פשוטה
    .claude/spy.sh --last       רק סכם את הסשן האחרון
    .claude/spy.sh --show       רק הדפס את התמליל הקריא, בלי לסכם
    .claude/spy.sh --live       סשן חדש עם פרשנות תוך כדי ריצה
    node .claude/spy.js <id>    תמליל של סשן מסוים
    node .claude/spy-live.js    להיצמד לסשן שכבר רץ

`claude … | tee log` **אינו** עובד לזה, ולא בגלל דקדוק: צינור על
stdout מסלק את ה-TTY, ומה שנכתב למסך הוא ציור — רצפי ANSI, מסגרות
וציור־מחדש של אותן שורות. הקובץ שנשמר אינו תמליל אלא צילום של
האנימציה. **ו-`mkfifo` אינו מציל את זה**: גם צינור בעל שם הוא צינור,
ה-TTY נעלם בדיוק כך, ו"שורה" בפלט כזה אינה אירוע אלא ציור — אין
טעם לספור עשר מהן ולסכם.

התמליל האמיתי כבר יושב על הדיסק: Claude Code כותב אותו בעצמו אל
`~/.claude/projects/<תיקייה-מקודדת>/<session-id>.jsonl`, שורת JSON
לכל אירוע. `spy.sh` מקבע מזהה סשן מראש (`--session-id`), מריץ בלי
צינור, ואז `spy.js` קורא את הקובץ שנוצר.

**פרשנות חיה** קוראת מאותו קובץ תוך כדי כתיבתו. `spy-live.js` מוסיף
לו כל שנייה את מה שנוסף, ומדי `--every` אירועים (ברירת מחדל 12), או
אחרי `--idle` שניות שקט, שולח את הקטע החדש ל-`claude -p` ומקבל שתיים
עד ארבע שורות בעברית פשוטה. הפירוק לשורות קריאות הוא בדיוק זה של
`spy.js` — אותה פונקציית `feed`, ולא העתק שלה.

הפרשנות אינה מודפסת לטרמינל של הסשן, מפני שהממשק של Claude Code
מצייר את המסך מחדש ודורס כל דבר שמודפס לתוכו. `--live` כותב אותה
אל `/tmp/claude-spy-live.txt` (או `$SPY_LOG`), ורואים אותה בטרמינל
שני עם `tail -f`. **כל הסבר הוא קריאה נוספת ל-claude, ולכן הוא עולה
כסף** — `--every` גדול יותר, פחות קריאות.

היצמדות לסשן שכבר רץ מתחילה מסוף הקובץ, כדי שההסבר הראשון לא יהיה
כל הסשן עד כה; `--from-start` כולל גם את מה שקדם. `--show` מדפיס את
האירועים בלי לקרוא ל-claude כלל, וזו הדרך לבדוק את המנגנון בחינם.

**"קבצים שנכתבו" מונה רק כלי `Write` ו-`Edit`.** קובץ שנכתב בתוך
פקודת Bash — heredoc, `sed -i`, הפניה — אינו מופיע שם. הרשימה
המלאה היא `git status`, וזה כתוב גם בפלט עצמו.

יש גם שורת **"אפליקציות שנזכרו בפקודות"**, והיא אזכור ולא שינוי:
מנייה של `<שם>/` בקלט של כל כלי. רשימת האפליקציות נגזרת בזמן ריצה
מכל תיקיית בת שיש בה `index.html` — לא רשימה קשיחה, שהייתה
מתיישנת באפליקציה הבאה שנוספת.
