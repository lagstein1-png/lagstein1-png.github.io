## הצוות

שבעה סוכני משנה ב-`.claude/agents/`, לכל אחד שם פרטי ותחום אחד:

| סוכן | תחום | Bash |
|---|---|---|
| `euclid` — אוקלידס | נכונות מתמטית, ואימות בחישוב ולא בעין | ✓ |
| `maayan` — מעיין | תוכן, ניסוח, ושלמות ארבע השפות | ✓ |
| `nimrod` — נמרוד | באגים, service worker, והרצה בדפדפן אמיתי | ✓ |
| `tamar` — תמר | האם רמת קושי באמת מלמדת, או שאפשר לנחש בה | ✓ |
| `renana` — רננה | הקראה ונגישות | ✗ |
| `bezalel` — בצלאל | זהות חזותית | ✗ |
| `gilad` — גלעד | ראש צוות, מכריע במחלוקות, **היחיד שמבצע commit** | ✓ |

היו עשרה, ושלושה תפקידים היו מכוסים פעמיים בשתי שיטות שמות:
`math-content-checker` מול `euclid`, `four-language-checker` מול
`maayan`, ו-`app-qa-runner` מול `nimrod`. הם אוחדו — הבודק נכנס אל
בעל השם, וסעיף שיטת האימות שלו נשמר במלואו בתוך הקובץ המאוחד.

**Bash אינו רשות לקמט.** ארבעה מהם מריצים את בדיקות ה-QA על מה
ששינו — זו בדיוק הסיבה שהוא ניתן להם. `gilad` הוא היחיד שמבצע
commit ודוחף, וגם מי שמוודא בסוף שהגרסה ומפתח הקאש עודכנו יחד.

**ומנהל העבודה אינו אחד מהשבעה — הוא הסשן הראשי.** אף אחד מקובצי
הסוכנים אינו נושא את כלי הסוכנים בשורת `tools:` שלו — שבע שורות,
`grep -n "tools:" .claude/agents/*.md` — ולכן סוכן **אינו יכול**
לקרוא לסוכן אחר. עד 9.9.2026 כל שבעת הקבצים טענו את ההפך, ״אתה
רשאי לקרוא לכל סוכן אחר בצוות״, וזו הייתה הבטחה שאין דרך לקיים:
סוכן שהאמין לה היה מתקן בעצמו דבר שאינו בתחומו, או שותק עליו.

במקומה: ממצא שאינו בתחום הסוכן נכתב בדוח בשורה
`לסוכן <שם>: <מה> — <קובץ:שורה>`, והסשן הראשי מזמן את הבא בתור.
`gilad` כותב את התוכנית — מי, על איזה קובץ, ובאיזה סדר — והפרוטוקול
המלא נמצא ב-`.claude/agents/gilad.md`, בסעיף ״חלוקת העבודה״. הכלל
שמחייב אותו: **קובץ אחד, סוכן אחד, ברגע אחד.** אפליקציה כאן היא
`index.html` יחיד, ולכן שני סוכנים שכותבים בה במקביל אינם שני
עובדים אלא דריסה — בלי שגיאה, בלי התנגשות ב-git, ועם תיקון אחד
שנעלם. מקבילות מותרת באבחון בלבד; התיקון עצמו הוא תור.
