שתים־עשרה אפליקציות לימוד שרצות בדפדפן, מדברות בקול, ועובדות
בלי אינטרנט אחרי הטעינה הראשונה.

**למי זה נבנה:** ללומד שקורא לאט, ללומד עם דיסלקציה או ADHD,
לעולה חדש שהעברית אינה שפת האם שלו, ולנהג מבוגר שחוזר ללמוד
אחרי שנים. **בין פתרון חכם לפתרון קריא — כאן בוחרים קריא**, וזה
מסביר כמעט כל החלטה בקוד.

**כרגע הכול פתוח בלי חיוב** — מבצע השקה, עד להודעה חדשה.

## איך זה בנוי

**כל אפליקציה היא `index.html` יחיד** — HTML, CSS ו-JavaScript
באותו קובץ. היוצא מן הכלל הוא `bagrut-806`, שהיא רב־קובצית.

- **Vanilla JS בלבד.** אין React, אין Vue, אין npm, אין build
  step, אין TypeScript, ואין תלות חיצונית.
- **PWA**: `manifest.json` ו-`sw.js` לכל אפליקציה, מטמון בשם משלה,
  והתקנה על מסך הבית.
- **עברית RTL**, ולרוב גם ערבית, רוסית ואנגלית.
- **הכול נשמר במכשיר.** התקדמות, הגדרות ושם — ב-`localStorage`
  בלבד. אין שרת שמחזיק אותם, ואין הרשמה.
- **אירוח:** GitHub Pages. אין build ואין pipeline — מה שיושב
  ב-`main` הוא מה שמוגש.

## שלוש מלכודות שמפילות, וכדאי לדעת עליהן לפני

**1. לגרסה יש שני מקומות, לא אחד.**

    var BUILD="b69 · 2026-09-10";                          // מה שהלומד רואה
    navigator.serviceWorker.register("sw.js?v=b69-pwa1");  // מה שקובע את הקאש

`sw.js` גוזר את שם המטמון מ-`?v=` שבכתובת הרישום, **לא** מ-`BUILD`.
עדכון של אחד בלי השני משאיר את הלומד עם הקוד הישן, בלי שום שגיאה.

**2. נגעת ב-`legal/` — העלה את כל שלושה־עשר המפתחות.** כל
`sw.js` מצרף את אותם קובצי `legal/` למטמון **שלו**, ומגיש אותם
משם בלבד. עותק מעודכן במטמון של אפליקציה אחרת אינו עוזר.

**3. מפתח `localStorage` שהועתק הוא מגירה משותפת.** כל
האפליקציות יושבות באותו מקור. אפליקציה שנולדה מהעתקה ונשארה עם
המפתח של המקור — ומבחן שנבנה באחת הופיע באחרת. זה קרה פעמיים.
`node .claude/qa/storage.js` תופס את זה.

## ״עזרה מהמורה״ (ג׳וש)

בוט שמסביר ואינו פותר במקום הלומד. **המוח כולו ב-`tutor-api/worker.js`**
ורץ ב-Cloudflare Workers — האתר סטטי, ומפתח API בקובץ סטטי הוא
מפתח פומבי.

מה נשלח: התרגיל שעל המסך, שפת הממשק, ומה שהלומד כתב.
**מה לא נשלח:** שם, התקדמות, הגדרות, ושום פרט מזהה. השיחה אינה
נשמרת ונמחקת במעבר לתרגיל הבא.

הוא **מחווט בכל שתים־עשרה האפליקציות וכבוי** — `API` ריק
ב-`tutor/tutor.js`, ולכן אין כפתור. ההפעלה:
`node .claude/qa/enable-tutor.js <כתובת>`.
