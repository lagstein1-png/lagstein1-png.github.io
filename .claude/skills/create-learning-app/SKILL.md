## שלב 1 — לבחור מאיזו משפחה מעתיקים

**זו ההחלטה היחידה שאי אפשר לתקן אחר כך בזול.** שלוש המשפחות אינן
מתורגמות זו לזו: סכימת תוכן שונה, מנגנון תרגום שונה, שלד קובץ שונה.

| התוכן שלך | העתק מ־ | סכימה |
|---|---|---|
| שאלות כתובות עם מסיחים | `ulpan` (החדשה והנקייה) | `{q, a, options:[{h, ok, why}], hint}` |
| שאלות שנוצרות בקוד | `math-uni3` | `{ask, expr, ans, wrong:[W], steps:[S], hint}` |
| תוכן ארוך, כתוב ביד, עם תתי־סעיפים | `bagrut-806` | `EXAM/QUESTION/SUB` בקובץ נפרד |

**ברירת המחדל היא `ulpan`.** היא משפחת החידון, ארבע שפות, המנגנון
הקריא ביותר (`T` + `t("key")`), והקטנה מבין השלוש.

**אל תעתיק מ-`math-app`.** לא מפני שחסר בו משהו — יש בו הכול: ארבע
שפות (`STR` + `T()`, 259 מפתחות), ששת מצבי הנגישות, ומודל החולשות
המפורט בפורטפוליו. אלא מפני שהוא **קורא לכל דבר בשם אחר**: בלי
מספור סעיפים, `LANGS` עם `label`+`flag` במקום `name`, `clear-font`
במקום `clear`, `hi-contrast` במקום `hc`. כל שורה שתעתיק ממנו תיראה
נכונה ולא תתפוס. הוא לא תבנית — הוא ניב.

*(אל תסיק מ-`grep` על שם ש״חסר״ משהו ב-`math-app`. שלוש קביעות כאלה
נכתבו במסמך הארכיטקטורה ושלושתן היו שגויות. פותחים את `defaults()`
ואת `applyModes` וקוראים.)*

**אל תערבב.** קוד מ-`math-teen` בתוך שלד של `ulpan` שובר את בורר
השפה בשקט — בלי שגיאה, בלי אזהרה.

## שלב 2 — שבעה מקומות, לא אחד

אפליקציה חדשה נוגעת בשבעה מקומות. **החמצת אחד = אפליקציה שלא
מופיעה, לא נטענת, או לא מתעדכנת.**

### 2.1 התיקייה

```
<app>/index.html      מהמשפחה שבחרת
<app>/manifest.json   name, short_name, description, id, theme_color
<app>/sw.js           קופי מדויק, ושורה 13 + שורה 25 בלבד משתנות
<app>/img/            icon-192, icon-512, icon-maskable-512, apple-touch-icon
```

`sw.js` — **שני הבדלים בלבד**, שניהם אותה מחרוזת:

```js
const CACHE = "<app>-" + V;                                    // שורה 13
keys.filter(k => k.startsWith("<app>-") && k !== CACHE)        // שורה 25
```

שם המטמון חייב להיות **ייחודי**. תחילית שחוזרת = ה-`activate` של
אפליקציה אחת מוחק את המטמון של השנייה.

אייקונים: `node .claude/qa/icon.js <תיקייה> <רקע> <צבע-קו> '<path…>'`

### 2.2 בלוק הקונפיגורציה

בסעיף 4 (״מצב ושמירה״). **שלוש שורות, וזה כל מה שמפריד בין מודול
המצב של אפליקציה אחת לשנייה:**

```js
var BUILD="<אות><מספר> · <תאריך>";
var SKEY="<app>-state-v1";
var GKEY_STORE="<app>-gkey";
```

`SKEY` ו-`GKEY_STORE` חייבים להיות ייחודיים — מפתח חוזר = שתי
אפליקציות דורסות זו את ההתקדמות של זו באותו דפדפן.

לאות ה-`BUILD` בחר אות שלא בשימוש. בשימוש כרגע:
`b` (math-app), `t` (math-teen), `u`/`v`/`g` (math-uni/2/3),
`n` (english), `m` (history), `a` (ulpan), `x` (bagrut-806).

### 2.3 עד 2.7 — דף הבית

`index.html` בשורש, וכולם בו:

| # | מה | איפה |
|---|---|---|
| 3 | רשומה ב-`DATA.APPS` | `id`, `cat`, `c`, `n`×4 שפות, `d`×4 שפות, `t`, `k` |
| 4 | סמל ב-`ICONS` | SVG 24×24, קו ולא מילוי, `aria-hidden` |
| 5 | ארבע מחרוזות `badge` | ״אחת־עשרה״ → ״שתים־עשרה״, וכן בערבית, רוסית ואנגלית |
| 6 | ארבע מחרוזות `lead` | מונות את התחומים בשם |
| 7 | מפתח הקאש של דף הבית | `sw.js?v=13-pwa1` → `14-pwa1` |

**`badge` ו-`lead` הן המלכודת.** המניין כתוב **כמילה, לא כספרה**,
ואינו נגזר מ-`DATA.APPS`. ארבע מחרוזות, ידנית, בכל אחת מהן.

לדף הבית אין `BUILD` — רק מפתח קאש. זה תקין.

## שלב 3 — התוכן

**סכימת התוכן היא של המשפחה שבחרת. פתח את הקובץ וחקה את המבנה
בדיוק. אין שדות בשם `h1` או `h2`.**

### התרגום — המלכודת השקטה

במשפחת `ulpan`/`english`/`history` המפתח הוא **מזהה אנגלי**
(`T.he.navHome`), וזה הפורמט הקל.

במשפחת `math-uni` המפתח הוא **המחרוזת העברית עצמה** (`_("...")`).
**שינוי מילה בעברית בלי לעדכן את המפתח מוחק את התרגום בשקט, בלי
שגיאה.** משנים את שניהם יחד.

ובכל מקרה: `TR_KEYS` הוא **מערך שורה־למפתח** (הפורמט של `math-uni`).
**אל תכתוב מילון בשורה אחת.** ב-`math-teen` המילון הוא שורה אחת של
219,430 תווים; כל שינוי בה מתנגש במלואו, ו-`git` יציע לבחור צד —
בחירה מוחקת מאות תרגומים.

**מיזוג מילון הוא איחוד, לא בחירת צד.** משווים מפתח־מפתח מול הבסיס
המשותף. רק מפתח ששני הצדדים שינו דורש הכרעה.

### מה שאסור

1. שירות או API בתשלום.
2. מפתח API בתוך הריפו. *(Gemini TTS מותר — המפתח נכנס בהגדרות
   ונשמר ב-localStorage. לעולם לא בקוד.)*
3. תלות חיצונית חדשה.
4. מחיקת תוכן קיים — שאלות, רמזים, תרגומים.

## שלב 4 — בדיקה, ולא בעין

```
node .claude/qa/serve.js &            # חובה ל-smoke ול-exam
node .claude/qa/parse.js <app>/index.html
node .claude/qa/smoke.js <app>        # דפדפן אמיתי
node .claude/qa/apps.js              # שבעת המקומות — ובראשם המניין
node .claude/qa/a11y.js              # ששת מצבי הנגישות מחווטים
node .claude/qa/cache.js             # BUILD מול ?v= בכל אחד־עשר
node .claude/qa/entropy.js <app>      # תשובה קבועה?
node .claude/qa/options.js <app>      # כמה אפשרויות באמת נראות
node .claude/qa/exam.js <app>         # אם יש מבחן כיתתי
```

`smoke.js` חייב לחזור `clean`. `cache.js` חייב לחזור **0 ממצאים**.

`options.js` מדווח `under4` — **זה לא בהכרח באג.** שאלה עם שלוש
תשובות אפשריות בסך הכול תקינה; ההבחנה היא לפי מקור האפשרויות, לא
לפי האחוז. הפירוט ב-`.claude/qa/README.md`.

**הרשת חסומה בסביבת הפיתוח.** בדיקה מול השרת המקומי היא בדיקה
מקומית — **לא קוראים לה ״בדיקה חיה״.**

## שלב 6 — מספר הגרסה מוקצה במיזוג

**בונים ומשאירים את המספר כפי שהוא. מי שממזג בודק את `main` ומקצה
מספר טרי.**

כל סשן מתפצל מ-`main`, רואה `b40`, ומסמן `b41`. שלושה סשנים עשו
בדיוק את זה באותו יום. **שתי גרסאות שונות עם אותו מפתח = מי שקיבל
אחת לא יקבל את השנייה לעולם** — בדיוק הבאג שהמנגנון נועד למנוע.

מיזגת ומצאת שהענף נושא מספר קיים — **זו התנגשות, לא צירוף מקרים.**

## §7 — נגעת ברוחבי

שכפול נקי אינו נוגע באפליקציות קיימות. אבל אם כן:

### `legal/` — כל אחד־עשר המפתחות יחד

אחד־עשר קובצי `sw.js` מצרפים מראש את **אותם** `/legal/terms.js`
ו-`/legal/protect.js`, כל אחד למטמון בשם משלו. ההגשה היא
`caches.open(CACHE)` ואז `c.match(req)` — **לא** `caches.match`
הגלובלי. לכן עותק ישן במטמון של אפליקציה אחרת אינו עונה כאן, אבל
העותק של כל אפליקציה משתחרר רק כשהגרסה שלה עולה.

**שינית `legal/` — העלה את אחד־עשר מפתחות הגרסה יחד.** אחרת חלק
מהמשתמשים יישארו על הישן לצמיתות.

`./img/` אינו נתון לזה — הנתיב יחסי, ולכן לכל אפליקציה כתובת משלה.

### ומזג מיד

**תיקון רוחבי שיושב בענף ולא מוזג ל-`main` יחזור וייפול.**
אפליקציה חדשה נולדת מהעתקה של קובץ ב-`main`, ולכן היא מעתיקה גם
את הבאג שכבר תוקן בענף שלא מוזג. **זה מה שקרה לאפליקציה
האחת־עשרה**, שנולדה עם באג מטמון שתוקן ימים קודם.

גמרת רוחבי — **מזג ל-`main` מיד, ולא בסוף הסשן.**
