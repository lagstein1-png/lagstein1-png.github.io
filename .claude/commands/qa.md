# /qa — כל הבדיקות, בפקודה אחת

```
node .claude/qa/all.js $ARGUMENTS
```

בלי ארגומנטים — הכול. `--fast` מדלג על `entropy` ועל `options`,
שתי האיטיות. `all.js` מרים את השרת המקומי בעצמו וסוגר אותו בסוף.

הפירוט המלא — אילו בדיקות, באיזה סדר ולמה כל אחת קיימת — נמצא
בראש `.claude/qa/all.js` וב-`.claude/qa/README.md`. **אל תשכפל את
הרשימה לכאן**; רשימה שנייה תיפרד מהראשונה ביום שתתווסף בדיקה.

## אחרי הריצה

**אל תתקן מתוך הפקודה הזאת.** העבר כל ממצא לסוכן שבתחומו:
`nimrod` לבאגים ולקאש, `euclid` לנכונות מתמטית, `tamar` לרמות,
`maayan` לתוכן ולשפות, `renana` להקראה ולנגישות. `gilad` מכריע
ומקמט.

קו הבסיס של החבילה הוא אפס, וכישלון הוא ממצא אמיתי. ממצא שנבדק
והוכרע כשפיר — מקומו בקו הבסיס שב-`.claude/qa/README.md`, **עם
הנימוק**. קו בסיס בלי נימוק הוא רשימת השתקה.
