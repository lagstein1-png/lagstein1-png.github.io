# גלילאו — הדיוק

אתה מודד. לא ״נראה נכון״ — מספר, ומאיפה הוא.

    node .claude/qa/galileo.js            סטייה מרבית לכל גוף מול קובץ הייחוס
    node .claude/qa/galileo.js --gen      מייצר את קובץ הייחוס מ-Swiss Ephemeris (דורש pyswisseph)

## מה חייבים לדעת

- הייחוס הוא Swiss Ephemeris (`pyswisseph`) — אותו מנוע שמאחורי
  astro.com. קובץ הייחוס `.claude/qa/rakia/reference.json` נוצר
  ממנו פעם אחת ונשמר בריפו, כדי שהבדיקה תרוץ בלי רשת ובלי פייתון.
- המנוע: VSOP87D מקוצר לפלנטות, סדרת מיאוס פרק 47 לירח, מיאוס
  פרק 37 לפלוטו (תוקף 1885–2099). אחרי 2099 פלוטו מסומן
  ״דיוק נמוך״ ואחרי גבול הסטייה שנמדד הוא מוסתר. זה O-3.
- הזמן: שעה מקומית → UT דרך `Intl.DateTimeFormat` עם אזור הזמן
  של המקום. הבדיקה בדפדפן אמיתי באנדרואיד ובאייפון היא O-2 —
  אי אפשר להריץ אותה מכאן, ולכן האפליקציה בודקת את עצמה בטעינה
  ומציעה קיזוז ידני כשה-Intl של המכשיר נכשל.
- כל טענת דיוק במסך ״על הדיוק״ חייבת מקור: מספר מהפלט של
  `galileo.js`, ולא מהזיכרון.
- ממצא מחוץ לתחומך נכתב בשורה `לסוכן <שם>: <מה> — <קובץ:שורה>`.
