# כימיה לבגרות

עשר יחידות לפי פרקי הליבה (70% היבחנות חיצונית) בתכנית הלימודים
בכימיה של משרד החינוך: מבנה האטום, מבנה אלקטרוני, הטבלה המחזורית,
מגמות בטבלה, קשרים כימיים, סטוכיומטריה, חמצון-חיזור, חומצות
ובסיסים, אנרגטיקה וקצב תגובה, כימיה של מזון. לכל יחידה שיעור קצר
ואחריו תרגול בשלוש רמות.

**אין כאן בנק שאלות.** כל שאלה מחושבת בזמן ריצה מפרמטרים שהוגרלו,
והתשובה אינה מאוחסנת בשום מקום — אותו קריטריון כמו ב-`math-g7`.

**קובץ אחד:** `index.html` (HTML + CSS + JS), ולצדו `manifest.json`,
`sw.js` ו-`img/`. אין תלות חיצונית ואין שלב בנייה.

## השלב שבו האפליקציה נמצאת

`public` — פורסמה 19.10.2026 באישור הבעלים אחרי תצוגה מקדימה
(וואטסאפ 20:36). המקור הוא `.claude/qa/stages.json`, ושם
`contentQA` הוא `cleared` (אישור בעלים, לא סריקת מורה).
התרגום לערבית, רוסית ואנגלית הוא תרגום מכונה הממתין לבדיקה —
מצוין גם בתוך האפליקציה.
