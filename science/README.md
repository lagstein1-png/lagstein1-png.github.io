# מדע ליסודי — מדע וטכנולוגיה לכיתות ג׳–ו׳ (מוסתר)

שיעורי מדע וטכנולוגיה ליסודי לפי מבנה מיקוד הלמידה של משרד החינוך
(תשפ״ג). התוכן נכתב במקור לאתר; המסמכים משמשים מבנה בלבד, עם קרדיט
וקישור לצד כל כיתה. מוסתר מאחורי ?internal=shlav-internal-science
עד אישור הבעלים וסקירת מורה.

שם העבודה "מדע ליסודי" הוא זמני — הבעלים קובע שמות (NAMING.md).

שלב v0 (s101): מסך יחידות לפי ארבע כיתות עם הנושאים המרכזיים,
ארבע שפות ממשק (he מקור; ar/ru/en תרגום מכונה לבדיקת מורה),
שער פנימי, מנוע ההקראה וההגדרות של math-app. יחידה ראשונה בתוכן
תגיע בשלב הבא.
