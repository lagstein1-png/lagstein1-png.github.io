# `tutor-api` — צד השרת של ״עזרה מהמורה״

**משרת את כל שתים־עשרה האפליקציות שבריפו הזה, ואת ״תאוריה
מדברת״ שאינה בו — שלושה־עשר תפקידים.** התשתית בדפדפן היא
`/tutor/tutor.js`, וכתובת השרת נכתבת שם — במשתנה `API`, פעם אחת
לכולן.

**זו אינה אפליקציה ואינה דף.** אין כאן `index.html`, אין `sw.js`,
והתיקייה אינה מוגשת ל-GitHub Pages כדף. היא הקוד שרץ במקום אחר —
בשירות פונקציות — ומחזיק את מפתח ה-API.

## למה זה קיים בכלל

האתר מתארח ב-GitHub Pages, שהוא **סטטי**. מפתח API בקובץ סטטי הוא
מפתח פומבי: כל מי שפותח את מקור הדף רואה אותו. לכן הבוט מדבר עם
הפונקציה הזאת, והיא — ורק היא — מדברת עם Anthropic.

**אין מפתח בקובץ הזה ולא יהיה.** הוא מגיע מ-Secret של הסביבה.

## מה יושב בשרת ולא בדפדפן

**הוראות המערכת** נמצאות ב-`worker.js` ואינן נשלחות מהדפדפן.
דפדפן אפשר לערוך; שרת לא. שתי שכבות:

- `CORE` — 32 שורות ההתנהגות, זהות בכל האפליקציות ובכל השפות.
  זו האישיות של ג׳וש — מי הוא, איך הוא מדבר, איך הוא מלמד ומה
  אסור לו — והנימוק של כל שורה נמצא ב-`JOSH.md` שבשורש המאגר.
  זה הבלוק שנשלח ראשון ולכן הוא זה שנשמר במטמון.
  **`node .claude/qa/tutor.js` נופל אם שורה כאן אינה מצוטטת
  ב-`JOSH.md` מילה במילה** — כדי שהמסמך והקוד לא ייפרדו.
- `ROLE` — תפקיד לכל אפליקציה, לפי המקצוע ורמת הלימוד. **שלוש־עשרה
  רשומות** (`node -e` על `worker.js`, 10.9.2026), ואפליקציה שאינה
  ברשימה נדחית ב-400. שתים־עשרה מהן מקומיות, והשלוש־עשרה היא
  ״תאוריה מדברת״ שיושבת בריפו נפרד וטוענת את `/tutor/tutor.js` מכאן.

**שפת התשובה** ו**השפה הנלמדת** נכנסות לבלוק המשתנה שאחריו.
בלימודי שפה (`english`, `ulpan`) המודל מתבקש לעטוף כל מילה
בשפה הנלמדת בסימנים `« »`, והדפדפן מקריא כל קטע כזה בקול של
אותה שפה — כך שפת ההסבר והשפה הנלמדת אינן מתערבבות.

הדפדפן שולח שלושה דברים בלבד: התרגיל שעל המסך, השפה, וההודעות
שהתלמיד כתב. לא שם, לא מזהה, ולא ההתקדמות שלו.

## פריסה — Cloudflare Workers

בלי npm ובלי build. הקובץ נועד להדבקה ישירה בעורך, ושלושת
הצעדים כאן הם כל מה שנדרש.

1. **Workers & Pages → Create → Worker.** לתת שם, ללחוץ Deploy
   על קוד הדוגמה כמו שהוא, ואז **Edit code** — למחוק הכול,
   להדביק את `worker.js`, ו-Deploy.

2. **Settings → Variables and Secrets**, ולהוסיף **שני** שדות:

       ANTHROPIC_API_KEY = המפתח        ← כ-Secret
       ALLOW_NO_RATE_LIMIT = yes        ← כ-Variable רגיל

   **Secret ולא Variable** למפתח: Variable נראה בממשק, Secret לא.

3. להעתיק את כתובת ה-`workers.dev` ולהריץ במאגר:

       node .claude/qa/enable-tutor.js https://tutor.xxx.workers.dev
       node .claude/qa/all.js

   הכלי עושה את כל השאר: כותב את הכתובת ב-`tutor/tutor.js`,
   מעלה את `LEGAL.version` ל-1.1, מעלה את שלושה־עשר מפתחות הקאש
   ומרענן את `STATUS.md`. `--off` מחזיר הכול לאחור.

### למה `ALLOW_NO_RATE_LIMIT` ולא KV

השרת מסרב לעבוד בלי מונה יומי, כי בלי מונה **אין תקרה יומית
כלל** — התקרות האחרות מגבילות אורך בקשה, לא כמות. המונה דורש
KV Namespace וקישור בשם `RATE`, וזה עוד שני מסכים בהקמה.

**החסם החזק ממילא אינו כאן.** אשראי מראש בחשבון Anthropic, בלי
טעינה אוטומטית, הוא תקרה קשיחה שאינה תלויה בקוד הזה, בהגדרה
שאפשר לשכוח, או בי. נגמר האשראי — הבוט מפסיק.

לכן ההמלצה: להצהיר `ALLOW_NO_RATE_LIMIT=yes`, לצאת לדרך, ולהוסיף
את ה-KV אחר כך אם רוצים תקרה יומית **בנוסף** לתקרת האשראי. אז זה
שני מסכים בשקט, לא בזמן הקמה ראשונה.

**מה שהוסר מהוראות אלה:** `ALLOW_ORIGIN` אינו נדרש —
`https://lagstein1-png.github.io` היא ברירת המחדל בקוד, וצריך
להגדיר אותו רק אם משנים דומיין.

## התקרות, ואיפה משנים אותן

הכול במשתנה `LIM` שבראש `worker.js`:

| | ברירת מחדל | מה זה חוסם |
|---|---|---|
| `msgs` | 14 | אורך השיחה שנשלח בחזרה בכל פנייה |
| `chars` | 300 | הודעה בודדת של התלמיד |
| `total` | 2000 | כל השיחה יחד |
| `perDay` | 20 | פניות ליום לכל כתובת IP |
| `globalPerDay` | 100 | תקרה יומית לכל השירות — **חסם העלות** |

`MAX_TOKENS` (700) חוסם את אורך התשובה, ו-`effort: "low"` מוריד
את עומק החשיבה. שני אלה הם רוב העלות של פנייה.

**המודל הוא `claude-haiku-4-5`** — נבחר להשקה כדי לחסום עלות.
החלפה היא שורה אחת (`MODEL`), ו-`CAP` שלידו כבר מטפל בהפרשים:
`effort` מחזיר שגיאה ב-haiku ו-`fallbacks` שייך למשפחת opus,
ולכן החלפת המודל לבדה — בלי `CAP` — הייתה שוברת כל פנייה ב-400.

**סדר העלייה המומלץ, אם התשובות רדודות מדי:** haiku →
`claude-sonnet-5` → `claude-opus-5`, ובכל שלב להסתכל בדף ה-Cost
שבקונסולה לפני הבא.

**מה שאפשר לחשב, ומה שלא.** מ-`MAX_TOKENS` ומהמחיר המפורסם
אפשר לגזור תקרה עליונה של **הפלט**: 100 פניות ביום כפול 700
טוקנים. הקלט מוסיף מעל זה, וכמותו לא נמדדה כאן — אין מפתח
בסביבת הפיתוח. **החשבון החודשי בפועל אינו ניתן לחיזוי מכאן.**

## שתי בדיקות שהשרת עושה על כל תשובה

1. **חשיפה מוקדמת** — בשני התורים הראשונים, תשובה שמכילה את
   הפתרון נפסלת. זה מה שאוכף ״רמז אחד בכל פעם״ מכנית ולא
   בהסתמך על ההוראות.
2. **משוואה שגויה** — כל ״א פעולה ב = ג״ בטקסט מחושב מחדש
   בשרת. `8 + 7 = 16` נפסל.

נפסל → ניסיון שני אחד, עם הערה מפורשת. נפסל שוב → נשלחת שאלה
מנחה קבועה שלעולם אינה מכילה את הפתרון.

מה ש**אינו** נבדק, בכוונה: מספרים שאינם בתרגיל. מורה שמפרק 17
ל-10 ו-7 כותב מספרים כאלה, וזו בדיוק ההוראה ״ייצוגים פשוטים״.

## בדיקה

    node .claude/qa/tutor.js

בודקת את השומרים, את האישיות (השם, אמוג׳י, סימני קריאה, וההצמדה
ל-`JOSH.md`), את אימות הקלט, את ההקשר שנשלח, את ארבע השפות
בתשתית, את החיווט של שתים־עשרה האפליקציות (תגית סקריפט, `mount`,
`open`, ו-`PRE` ב-`sw.js`) ואת שער התנאים. אינה פונה לרשת ואינה
עולה כסף.
