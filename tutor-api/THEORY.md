# ״תאוריה מדברת״ — החיווט מוכן, וצריך יד אחת להחיל אותו

האפליקציה השתים־עשרה יושבת **בריפו נפרד**, ולכן הקומיט שלה אינו
כאן. הסוכן בסביבה הזאת קיבל **גישת קריאה בלבד** לריפו ההוא —
בקשת דחיפה נחסמה (״Permission for this action was denied by the
Claude Code auto mode classifier״). לכן החיווט נבנה, נבדק בדפדפן
אמיתי, ונשמר כאן כתיקון להחלה.

## למה זה עובד בכלל בין שני ריפו

שני הריפו מתפרסמים תחת **אותו מקור** — `lagstein1-png.github.io`
— הראשי בשורש והשני תחת שם הריפו שלו. לכן `/tutor/tutor.js`
בנתיב מוחלט נפתר אל הקובץ שבריפו הראשי, בדיוק כמו `/legal/`
שכבר עובד ככה היום.

**מה שאין בריפו ההוא ולא יהיה:** הוראות מערכת, פרומפט ומפתח API.
הכול בשרת.

## החלה

    git -C <הריפו-הנפרד> apply --check /נתיב/אל/tutor-api/theory.patch
    git -C <הריפו-הנפרד> apply         /נתיב/אל/tutor-api/theory.patch

`--check` קודם, ולא כנוהג טוב אלא מפני שזו הדרך היחידה לדעת אם
ההקשר בריפו ההוא זז מאז שהתיקון נכתב.

## מה התיקון עושה — חמש נגיעות

1. `<script src="/tutor/josh-face.js">` ואחריו
   `<script src="/tutor/tutor.js">`, **לפני** הסקריפט של האפליקציה.
2. `TUTOR.mount({app:"theory", …})` **בתוך ה-IIFE** של האפליקציה.
3. כפתור `#btnTutor` ליד ״רמז״ ו״דלג״.
4. שלושת הנתיבים המשותפים ל-`PRECACHE` שב-`sw.js`:
   `/tutor/josh-face.js`, `/img/josh.jpg` ו-`/tutor/tutor.js`.
5. `BUILD` מ-`v98` ל-`v99`. שם `BUILD` הוא מקור אמת אחד ומפתח
   הקאש נגזר ממנו, בשונה מהאפליקציות שבריפו הזה.

**סעיפים 1 ו-4 הורחבו 13.9.2026, והתיקון היה מתיישן בשקט בלעדיהם.**
הוא נכתב לפני שכבת הפנים, ולכן צירף `/tutor/tutor.js` לבד — ואילו
היה מוחל כך, תאוריה הייתה מקבלת ג׳וש **בלי פנים**: `tutor.js` קורא
ל-`JOSHFACE` בתוך `build()`, הקריאה מוגנת ב-`typeof`, ולכן אין
שגיאה ואין סימן. `node .claude/qa/tutor.js` אוכף את זה מעכשיו,
והרשימה שם **נגזרת** מה-`PRE` של שתים־עשרה האפליקציות ולא כתובה
ביד — כך שנתיב משותף שיתווסף להן בעתיד ייפול כאן מעצמו.

**סדר הטעינה אינו קוסמטי:** בסדר הפוך גם כן אין שגיאה, ופשוט אין
פנים. יש בדיקה גם עליו.

## מה אינו בתיקון, במכוון

**`josh-state.js` אינו שם.** גלאי מצב הלומד בטייס ב-`math-app`
בלבד (שלב 3), והפצה היא החלטה נפרדת. תאוריה תקבל אותו כשכל
האפליקציות יקבלו אותו, ולא לפני.

## איך אומת שהתיקון עדיין תקין

הריפו הנפרד אינו נגיש מכאן, ולכן `git apply --check` מולו אינו
אפשרי — וזה נאמר במפורש כדי שלא ייקרא כאן יותר ממה שנמדד.

מה שכן נמדד, 13.9.2026: **עץ סינתטי שנבנה מתוך התיקון עצמו.**
כל שורת הקשר של כל היתוך הושמה במספר השורה שהיתוך מצהיר עליו,
ואז:

    git apply --check   ✓ עובר
    patch -p1 --dry-run ✓ עובר, בלי fuzz

זה מוכיח שהחשבון של ההיתוכים נכון ושהעריכה לא שברה אותו. הוא
**אינו** מוכיח שההקשר בריפו ההוא לא זז מאז; לזה צריך
`git apply --check` שם, והוא הפקודה שלפני ההחלה.

**סעיף 2 הוא לא קוסמטיקה.** בגרסה הראשונה החיבור ישב **מחוץ**
ל-IIFE, ושם `S`, `FLOW` ו-`stopSpeech` אינם קיימים. ה-`catch`
בלע את זה: הפאנל נפתח, אבל `expr` ו-`ans` יצאו ריקים והשפה
נשארה עברית תמיד. נמדד בדפדפן, וזו הסיבה שהחיבור עבר פנימה.

## מה שכבר קיים כאן ואינו צריך שינוי

התפקיד של האפליקציה נמצא ב-`worker.js`, ב-`ROLE.theory`. בלעדיו
`readBody` היה דוחה אותה ב-400. `node .claude/qa/tutor.js` בודק
שהוא קיים — אבל **אינו** בודק את החיווט שבריפו ההוא, שאינו כאן.

## ממצא בדרך: יש שם וו לבוט שכבר לא מחובר לכלום

בשורה `const EXPLAIN = { url:'/.netlify/functions/explain',
enabled:false, … }` יושבת יכולת הסבר קיימת, מכובה, שמצביעה
לפונקציית Netlify — ו-**Netlify כבר אינו בשימוש**. התיקון הזה
אינו נוגע בה: היא מכובה ואינה מזיקה, ומחיקה היא החלטה של הבעלים.
כשתופעל ״עזרה מהמורה״ היא מכסה את אותו צורך דרך שרת אחד.
