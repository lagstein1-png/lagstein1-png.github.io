# ״תאוריה מדברת״ — החיווט מוכן, וצריך יד אחת להחיל אותו

האפליקציה השתים־עשרה יושבת **בריפו נפרד**, ולכן הקומיט שלה אינו
כאן. הסוכן בסביבה הזאת קיבל **גישת קריאה בלבד** לריפו ההוא —
בקשת דחיפה נחסמה (״Permission for this action was denied by the
Claude Code auto mode classifier״). לכן החיווט נבנה, נבדק בדפדפן
אמיתי, ונשמר כאן כתיקון להחלה.

## למה זה עובד בכלל בין שני ריפו

שני הריפו מתפרסמים תחת **אותו מקור** — `lagstein1-png.github.io`
— הראשי בשורש והשני תחת שם הריפו שלו. לכן `/tutor/tutor.js`
בנתיב מוחלט נפתר אל הקובץ שבריפו הראשי, בדיוק כמו `/legal/`
שכבר עובד ככה היום.

**מה שאין בריפו ההוא ולא יהיה:** הוראות מערכת, פרומפט ומפתח API.
הכול בשרת.

## החלה

    git -C <הריפו-הנפרד> apply /נתיב/אל/tutor-api/theory.patch

## מה התיקון עושה — ארבע נגיעות

1. `<script src="/tutor/tutor.js">` **לפני** הסקריפט של האפליקציה.
2. `TUTOR.mount({app:"theory", …})` **בתוך ה-IIFE** של האפליקציה.
3. כפתור `#btnTutor` ליד ״רמז״ ו״דלג״.
4. `/tutor/tutor.js` ל-`PRECACHE` שב-`sw.js`, ו-`BUILD` מ-`v98`
   ל-`v99`. שם `BUILD` הוא מקור אמת אחד ומפתח הקאש נגזר ממנו,
   בשונה מהאפליקציות שבריפו הזה.

**סעיף 2 הוא לא קוסמטיקה.** בגרסה הראשונה החיבור ישב **מחוץ**
ל-IIFE, ושם `S`, `FLOW` ו-`stopSpeech` אינם קיימים. ה-`catch`
בלע את זה: הפאנל נפתח, אבל `expr` ו-`ans` יצאו ריקים והשפה
נשארה עברית תמיד. נמדד בדפדפן, וזו הסיבה שהחיבור עבר פנימה.

## מה שכבר קיים כאן ואינו צריך שינוי

התפקיד של האפליקציה נמצא ב-`worker.js`, ב-`ROLE.theory`. בלעדיו
`readBody` היה דוחה אותה ב-400. `node .claude/qa/tutor.js` בודק
שהוא קיים — אבל **אינו** בודק את החיווט שבריפו ההוא, שאינו כאן.

## ממצא בדרך: יש שם וו לבוט שכבר לא מחובר לכלום

בשורה `const EXPLAIN = { url:'/.netlify/functions/explain',
enabled:false, … }` יושבת יכולת הסבר קיימת, מכובה, שמצביעה
לפונקציית Netlify — ו-**Netlify כבר אינו בשימוש**. התיקון הזה
אינו נוגע בה: היא מכובה ואינה מזיקה, ומחיקה היא החלטה של הבעלים.
כשתופעל ״עזרה מהמורה״ היא מכסה את אותו צורך דרך שרת אחד.
